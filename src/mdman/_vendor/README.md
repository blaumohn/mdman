# Third-party code and data

## pylatexenc 3.0b2

The Python files under `pylatexenc/` are copied verbatim from
[commit 22f719a4063610bdc6ff819a0a6084e344308a0f](https://github.com/phfaist/pylatexenc/tree/22f719a4063610bdc6ff819a0a6084e344308a0f)
and match the corresponding files in the
[3.0b2 wheel](https://pypi.org/project/pylatexenc/3.0b2/#files).
The copy lives under the private `mdman._vendor` namespace and omits the
standalone command-line entry points and the Unicode-to-LaTeX encoder.

The [MIT license](pylatexenc/LICENSE.txt) and the upstream
[W3C notice](pylatexenc/LICENSE.unicode.xml) for the Unicode XML data used
by the symbol definitions are included.
